## Tool Details
- **Name:** Talkwell
- **Repo:** ben-gy/talkwell
- **Category:** p2p-communication (privacy in the public directory)
- **Audience:** friends wanting a quick private natter; groups coordinating over push-to-talk (gamers, hikers, event crew); anyone who won't install another calling app or hand over a phone number.
- **Stack:** Vite 6 + vanilla TypeScript + Vitest
- **Browser APIs:** WebRTC (trystero/nostr), getUserMedia (mic), Web Audio (AnalyserNode + MediaStreamDestination), MediaRecorder, Web Crypto (PBKDF2 + SHA-256), Screen Wake Lock, Web Share / Clipboard / qrcode, Service Worker (PWA)
- **Worker strategy:** main-thread — a live call is event-driven; metering + recording are lightweight. No CPU-heavy batch work to offload.

## Privacy Model
- **Protected:** microphone audio travels full-mesh, browser-to-browser, DTLS-SRTP encrypted, with no media server in the path; the room passphrase (link-hash only) encrypts the signalling handshake and derives the SAS; walkie-talkie mode transmits nothing until held; nothing is recorded unless you press Record, and recordings are local files never uploaded.
- **Not protected:** public nostr relays learn an ephemeral room id + that browsers are connecting (handshake is passphrase-encrypted); your IP is visible to peers + the public STUN server (inherent to any VoIP/P2P call); a symmetric-NAT pair with no TURN may fail to connect (we run no TURN); anyone with the full link can join.
- **Trust surface:** the static bundle + its TLS chain; the public signalling relays + STUN (encrypted handshake only); a cookie-less Cloudflare Web Analytics beacon (no audio); the feedback widget (only if opened + Send pressed).

## Architecture Decisions
- **Audio-only sibling of meetwell** (built 2026-07-29). Reused the proven trystero/nostr recipe (see the trystero-p2p-recipe memory): `trystero/nostr` not the deprecated `trystero/torrent`; the new `makeAction`-object API; settable `onPeerJoin`/`onPeerStream` properties; password-encrypted signalling + full-mesh DTLS-SRTP + a four-word SAS as the honest E2E story (no per-frame Insertable-Streams layer, which trystero doesn't expose and which is redundant for a full mesh).
- **Distinct from meetwell, not video-removed:** a fresh violet/comms visual identity, speaker-orb cards with reactive level rings instead of video tiles, and the central new mechanic — **push-to-talk**. The transmit decision lives in a pure `shouldTransmit({mode, muted, held, listenOnly})` function (unit-tested) that drives the outgoing audio track's `enabled` flag; the on-screen talk button (pointer hold) and the Space bar both feed it. Open-mic mode makes the same button a mute toggle.
- **Recorder is audio-only:** a Web Audio `MediaStreamDestination` mixdown → `MediaRecorder` Opus/WebM, far simpler than meetwell's canvas-composite video recorder; the artefact is a small `.webm` audio file.
- **iPhone earpiece note:** for a live-mic *call* this is expected behaviour, so — per the voxwell/#6 memory — Talkwell detects iPhone/iPod (excludes iPad) and shows an honest note ("hold to your ear like a call, or use headphones") rather than a speaker toggle that can't work.
- Own app-id (`talkwell-v1-…`) and PBKDF2 salt (`talkwell:v1:`) so rooms never collide with meetwell.

## Verification (what was and wasn't possible)
The in-app Browser pane blocks arbitrary `localhost` navigation and the Chrome extension
was unresponsive in this unattended run, so verification ran through the pane's own
`preview_start` dev-server (launch.json) on the built `dist/`.

Confirmed:
- Lobby renders; microphone blocked in the pane → **first-class listen-only join** engaged with a clear message.
- `[hidden]` overlay guard holds: `#drawer` and `#modal-host` are `display:none` on load; `elementFromPoint(centre)` returns the real speaker grid (not an overlay) on both desktop and a 375 px mobile viewport.
- Privacy nav button is labelled **"Privacy"**; the modal has Protected/Not-protected/Trust-surface sections plus the mandated Cloudflare-beacon and feedback disclosures. How-it-works (7 steps) and About modals open; Escape and × close all of them.
- Event-log drawer opens (flex) and closes via its × on desktop **and** at 375 px.
- **Two-tab P2P over the real public nostr relays:** both tabs joined the same room, discovered each other (people count 2, "Peer joined"), derived an **identical four-word SAS** (`river · cargo · heron · birch`), and a chat message crossed the encrypted data channel B→A.
- PWA: manifest resolves with `display:standalone`, a `maskable` icon and 5 icons; `apple-touch-icon.png` returns 200 image/png; `third-party-notices.txt` served.
- No console errors.

**Not verifiable in this pipeline (stated plainly):** the automation cannot speak and the
preview browser blocks `getUserMedia`, so **no real-device voice call, no live push-to-talk
transmission, and no recording artefact were exercised end-to-end**. The transmit gate and
recorder helpers are covered by unit tests; the mic-denied listen-only path — the exact path
every permission-denier takes — *is* what the two-tab dry-run drove, in full.

## Errors & Resolutions
- The in-app Browser pane refused direct `localhost` navigation ("blocked by policy") and the
  Chrome extension timed out. Resolved by using the pane's `preview_start` with a launch.json
  entry pointing at the built tool (the sanctioned dev-server path), which opened the localhost
  tab successfully and allowed the full two-tab P2P dry-run.
