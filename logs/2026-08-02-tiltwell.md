## Tool Details
- **Name:** Tiltwell
- **Repo:** ben-gy/tiltwell
- **Category:** sensor-tools (index category: live-dashboards)
- **Audience:** DIYers, roofers/solar installers, accessibility auditors, tripod-levelling photographers
- **Stack:** Vanilla TypeScript + Vite 6 + Vitest; no runtime dependencies
- **Browser APIs:** DeviceOrientation (beta/gamma), DeviceMotion accelerationIncludingGravity, DeviceOrientationEvent.requestPermission (iOS), Screen Orientation, Canvas 2D + DPR, Pointer Events, Screen Wake Lock, Web Share, Clipboard, File System Access, Service Worker (PWA)
- **Worker strategy:** main-thread only (per-frame maths is trivial); setInterval render loop (a hidden tab throttles rAF), deferred setTimeout first-draw so the gauge sizes after layout

## Privacy Model
- **Protected:** the orientation stream is read per-frame and discarded; captures live only in the tab; no reading, CSV, image or photo is ever uploaded; a photo loaded for the protractor never leaves the tab.
- **Not protected:** the initial page load is an ordinary web request (GitHub Pages sees IP/browser); exported files are the user's to share.
- **Trust surface:** hash-pinned static bundle + TLS; cookie-less Cloudflare Web Analytics beacon (page views only); feedback only when the user presses Send.

## Architecture Decisions
Vanilla TS — a single instrument surface, no multi-pane state to justify React.
The canonical intermediate is a **unit gravity direction** in the device frame:
DeviceOrientation beta/gamma (or DeviceMotion's gravity vector) are both converted
to that one vector, and every angle (tilt-from-horizontal, signed per-axis for the
bubble, long-axis slope for the clinometer) is derived from it. This isolates the
platform sign-quirks in one place and makes the whole derivation a pure function —
essential, because the automation cannot tilt a real phone. Screen rotation is
compensated with a pure in-plane rotation. The photo protractor stores points in
image coordinates against a contain-fit mapping so exports are full-resolution.

world**, so the page's synthetic-sample test hook (`window.__tiltwell`) was
